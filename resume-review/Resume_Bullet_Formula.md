# Resume Bullet Formula — Weak vs Strong

Use this pattern for every bullet: **Action verb + what you built + tech stack + measurable impact**.

---

## MGM Example (your case)

### Weak
> Designed and developed independently deployable microservices for User Roles, Month-End Process, and Month-End Adjustment using Spring Boot and JPA.

**Why it scores low:** Generic verbs ("designed and developed"), no number, reads like a task list.

### Strong
> Architected and delivered three critical microservices: User Roles, Month-End Process, and Month-End Adjustment, reducing deployment times for new features by 40%.

**Why it works:**
| Element | Example |
|---------|---------|
| Strong verb | Architected and delivered (not "designed and developed") |
| Scope | three critical microservices — shows count |
| Named deliverables | User Roles, Month-End Process, Month-End Adjustment |
| Metric | 40% reduction in deployment times |

### Best (ATS + impact — use in resume)
> Architected and delivered **three critical microservices** — User Roles, Month-End Process, and Month-End Adjustment — using **Spring Boot** and **JPA**, reducing deployment times for new features by **40%**.

Adds tech keywords for ATS while keeping the impact line.

## Verb Upgrade Table

| Replace (weak) | Use (strong) |
|----------------|--------------|
| Designed and developed | Architected and delivered |
| Worked on | Led / Drove / Spearheaded |
| Responsible for | Owned / Delivered / Achieved |
| Helped with | Enabled / Accelerated |
| Involved in | Executed / Implemented |
| Used | Leveraged / Applied |
